# WankaAgro Track

Plataforma web full-stack de trazabilidad agrícola y comercio directo sin intermediarios para productores y compradores del Valle del Mantaro (Huancayo, Concepción y Chupaca).

## Arquitectura y Stack Tecnológico
* **Backend:** FastAPI (Arquitectura por capas: APIs, Services, Schemas, Database) + `pyodbc`.
* **Base de Datos:** SQL Server (`WankaAgroDB`) con esquema maestro-detalle (`Pedidos` / `Detalle_Pedidos`) y control transaccional de stock.
* **Frontend:** Angular (Standalone Components, Signals, Zoneless) + Bootstrap 5.
